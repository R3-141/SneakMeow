\# SneakMeow 🐟🐱



（这是我创造的第一个服务器插件）



一个有趣的 Minecraft Paper 插件，让玩家在手持鱼类时潜行会发出喵叫声！



\## 功能特点



\- 🎣 持鱼触发喵叫

\- 🐱 可爱的猫叫声

\- 🔊 附近玩家可听到

\- ⏰ 智能冷却系统

\- ⚙️ 简易配置，安装后无需配置即可生效



\## 安装



1\. 下载 `SneakMeow.jar`

2\. 放入服务器 `plugins` 文件夹

3\. 重启服务器



\## 使用



手持鱼类 + 潜行 = 喵~ 



\## 支持版本



\- Paper 1.21.x

\- 向下兼容 1.20.x
